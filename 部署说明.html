📲 部署成手机可访问的网址

数据只存在你设备本地，部署只是把"界面"放到网上，别人看不到你的数据。
1准备这个文件夹

就是 deploy 文件夹，里面已有：index.html、weight.html、stock.html、manifest、图标、sw.js。整个文件夹一起用。

2最省事：Netlify Drop（拖进去就行）

① 打开 app.netlify.com/drop
② 建议先免费注册/登录一个账号（方便以后改）
③ 把整个 deploy 文件夹拖到页面上
④ 几秒后自动生成网址，如 xxx.netlify.app

3替代：Vercel

① 打开 vercel.com 注册登录
② New Project → 从 GitHub 导入（先把 deploy 推到你的 GitHub 仓库），或直接用 Vercel CLI 部署
③ 得到 xxx.vercel.app 网址

4手机：添加到主屏幕（关键一步）

① 手机浏览器（Safari / Chrome）打开你的网址
② 点浏览器「分享」→ 添加到主屏幕
③ 桌面出现图标，以后点它就像用 App，离线也能开

5想保密？

网址别乱发；或让我给网页加个打开密码。换手机前，记得在网页里点「导出」备份数据。
